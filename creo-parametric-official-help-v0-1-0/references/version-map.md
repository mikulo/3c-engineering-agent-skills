## 使用规则

- 根入口返回正常页面不代表某个具体主题存在。回答前仍须打开支持结论的具体主题页。
- PTC 帮助中的锚点 URL 可以直接指向主题，例如 `index.html#page/...`；引用时优先链接具体主题页。
- 中文主题搜索不到时，可在同一版本的 `usascii` 英文帮助中检索，但回答中说明使用了英文官方页面。
- 3–6 的同结构路径在核验时跳转到 PTC 404 页面。不要把 404 最终页的 HTTP 200 当成帮助可用。
- Creo 3.0 补充 PDF 是官方配置选项清单，但不是完整帮助中心；只能支持 `config.pro` 相关结论。
- 用户明确指定的版本没有可用帮助时，按主版本号的绝对差选择最近的已验证帮助版本；回答中必须同时标出目标版本和参考版本。当前版本表中 Creo 3–6 的最近可用版本均为 Creo 7。
- 用户未指定版本时不使用“最近版本”规则，固定采用 Creo 12 并提示。
- 若将来找到 3–6 的 PTC 官方存档，可在验证具体主题可打开后更新此表；第三方镜像不算官方入口。
