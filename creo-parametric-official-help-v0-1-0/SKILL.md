# Creo Parametric Official Help

以“可定位的 PTC 证据”为回答前提。不要仅凭记忆给出配置项、允许值、默认值、文件名、菜单路径或版本兼容性。

## 不可违反的约束

- 不得编造、补全或猜测不存在的 `config.pro` 选项、绘图 detail/dtl 选项、值、默认值或界面命令。
- 不得把其他 PTC 产品（Creo View、Creo Elements/Direct、Creo+ 等）的说明当作 Creo Parametric 说明。
- 找不到足够证据时，明确说“在已核验的 PTC 资料中未找到”，并说明查过的版本和来源；不要给出“可能是”式配置建议。
- 把“未检索到”与“选项不存在”区分开。只有来源明确断言不存在或已移除时，才能这样下结论。
- 对任何会写入配置文件的示例，只使用来源中实际出现的选项名和值。路径等用户自定义值必须标注为示例占位值。

## 确定版本

1. 从用户文字中提取 Creo Parametric 主版本，例如 12、12.0 或 12.4.5.0 均按主版本 12 路由，但保留用户给出的完整版本用于说明。
2. 读取 [references/version-map.md](references/version-map.md)，使用目标主版本的中文官方帮助入口。
3. 用户未给版本时，使用 Creo 12，并在回答开头明确写明：“你未指定版本，以下按 Creo 12 官方帮助核验。”
4. 用户明确指定的版本没有已验证入口、入口失效或找不到所需主题时，改用数值上最接近且能支持该主题的已验证版本，并明确写明“目标版本”和“实际参考版本”。例如 Creo 4–6 优先参考 Creo 7，而不是 Creo 12。不得暗示参考版本的行为一定适用于目标版本。
5. 对版本表之外的新版本，先在 `support.ptc.com/help/creo/creo_pma/` 下检索并打开精确版本页面；验证成功才能使用。找不到时同样选择最接近的已验证版本。用户没有指定版本的情况不使用最近版本算法，仍按第 3 条默认 Creo 12。

版本入口会变化。若问题依赖精确版本行为，应在本次回答中重新打开目标页面，而不是只相信版本表的历史核验状态。

## 按问题类型取证

### `config.pro`

先读取 [references/config-pro-source.md](references/config-pro-source.md)，并按其中命令检索随附索引。

- 无论用户是否知道选项名，都必须先检索本地 Creo 12.4.5.0 配置选项资料。
- 用户给出选项名时，先按完整英文名精确检索；只报告命中的说明、允许值与默认值。
- 用户只给自然语言目标时，先检索 2–4 个最有区分度的中英文关键词，再对候选英文选项名做一次精确检索。候选词本身不是证据。
- 目标版本为 12 时，以随附 PDF 为 `config.pro` 主依据；可用 Creo 12 在线帮助补充操作步骤。
- 若版本表列出该目标版本的 PTC 官方补充配置手册（目前包括 Creo 3.0），先用该手册核验 `config.pro`，再把 Creo 12.4.5.0 PDF 作为对照；补充手册不能替代完整版本帮助来证明菜单或一般软件行为。
- 目标版本不是 12 时，优先用目标版本官方帮助确认版本行为；目标帮助不可用时使用按版本规则选出的最近参考版本，同时把 PDF 作为 12.4.5.0 对照。若选项只在一方出现，清楚说明目标版本、参考版本和资料版本，不做跨版本外推。
- PDF 中未命中时，继续查目标版本或最近参考版本的 PTC 官方帮助。只有官方帮助明确记录该选项时才能给出配置行，并说明它未出现在随附的 12.4.5.0 清单中；若使用的是最近参考版本，不得声称已在目标版本核验。

### 绘图 detail/dtl 选项

`config.pro` 与绘图详细信息选项不是同一套配置。不要用随附的 `config.pro` PDF 证明 `.dtl` 选项。

- 在目标版本帮助的“详细绘图 / Detail”范围内检索准确选项名、值域、默认值和作用域；目标帮助不可用时使用最近参考版本并明确标注。
- 区分活动绘图、绘图模板、3D 模型详细信息选项以及外部 `.dtl` 文件；来源未说明时不要自行归类。
- 只有帮助页面明确给出语法或值时才输出可复制的 `.dtl` 行。

### 软件设置与故障排查

- 优先使用目标版本 Creo Parametric 官方帮助中的操作步骤、限制与前置条件；目标帮助不可用时使用最近参考版本并明确标注。
- 若问题可能是安装、许可、显卡、Windchill 或其他模块问题，先确认产品和模块边界，再检索对应 PTC 官方资料。
- 不把旧版菜单位置直接套用到新版；若只能找到不同版本页面，必须展示版本差异警告。

## 官方资料与社区资料

读取 [references/community-source-policy.md](references/community-source-policy.md)。可在检索 PTC 官方帮助的同时检索 PTC Community，也可根据问题性质只查官方资料；不必等官方资料无结果后才查社区。社区方案必须标记为“PTC Community 经验/变通方法”，并展示帖子涉及的 Creo 版本和日期；社区帖子不能单独证明某个配置项在目标版本中存在。

若官方资料与社区帖子都有结果，在答案中分开标注“PTC 官方资料”和“PTC Community”，说明二者各自支持的结论。社区可补充实际现象、排查顺序和变通方法，但不能覆盖官方资料中的明确选项定义、值域、默认值或版本说明。二者冲突时展示冲突，不要静默选边或合并成一个结论。

不得使用第三方博客、聚合站或未经 PTC 托管的选项表来填补空白，除非用户明确要求扩展到第三方资料；即使如此也不能把它描述为官方结论。

## 回答格式

答案应让工程师能快速审计：

1. 先写本次采用的 Creo 版本和资料版本。
2. 直接给结论；若无法核验，直接说无法核验。
3. 给出最少但完整的操作步骤或配置行。
4. 对配置项列出准确名称、允许值、默认值（来源提供时）、作用域和生效条件。
5. 紧邻相关结论提供可打开的 PTC 页面链接；本地 PDF 结论注明“Creo 12.4.5.0 配置选项 PDF”及 PDF 页码。
6. 单列版本差异、重启/重新载入要求以及可能覆盖设置的配置层级，但仅在来源支持时写入。
7. 同时使用官方和社区资料时，分别标注来源，不把社区经验改写成官方结论。

优先转述，不大段复制来源。保留英文选项名、值和产品 UI 中必要的中英文字段，避免翻译改变精确标识符。
